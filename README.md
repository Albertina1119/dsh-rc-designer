# RC 飞行器总体设计引擎

在线版：锚点驱动的固定翼 / 多旋翼 / 直升机总体设计方案推荐工具。
**纯前端、零依赖、零后端**，所有计算在浏览器本地完成，不上传任何数据。

👉 打开站点根目录的 `index.html` 即可使用。

## 这个仓库是什么

一个可直接托管在 GitHub Pages / Netlify / Vercel / 任意静态主机的静态站点。

| 文件 | 说明 |
|---|---|
| `index.html` | 主程序界面（单文件，含全部 UI 与交互） |
| `airfoil-lib.js` | 翼型库与气动公式库：NACA 4/5/6 位几何生成、28 个翼型数据库、任意编号解析与性能估计、翼型推荐器 |
| `design-engine.js` | 设计引擎：8 类机型设计区间、锚点池、维度识别、参数补全、公式计算、约束校验、多目标评分、候选池择优、Top3、锁定重算、命名、快照 |
| `xlsx-export.js` | 零依赖 Excel 导出器（自实现 CRC32 + ZIP + OOXML），导出 18 个工作表 |
| `.nojekyll` | 告诉 GitHub Pages 跳过 Jekyll 处理 |

## 功能

- **机型**：练习机 / 滑翔机 / 3D 特技 / 竞速 / 载重 FPV / 长航时 / 多旋翼 / 直升机，也可留空由锚点自动识别
- **锚点**：19 个锚点任选，数量不设上限（至少 2 个），覆盖几何 / 重量 / 动力 / 性能 / 风格 5 个维度中的至少 2 个
- **参数**：模板基线 + 规则库联立求解（面积 ⇄ 翼展 ⇄ 展弦比 ⇄ 翼载 ⇄ 重量 互推），逐项标注来源
- **尺寸**：机身长度、机翼平均弦长 / 根弦 / 尖弦 / MAC、尾翼面积与尾臂，并校核机身长度/翼展比值
- **翼型**：内置 28 个 NACA 翼型，按机型 / 雷诺数 / 升力需求推荐 Top3，支持手动输入任意编号校验
- **公式**：翼面积、展弦比、MAC、翼载、推重比、失速速度、雷诺数、尾容量、重心与静稳定裕度、L/D、爬升率、碳管主梁、舵机扭矩等 37 条
- **校验**：数值范围 / 经验区间 / 交叉冲突三类，分「不通过 / 警告 / 通过」
- **择优**：45 套候选池 → 硬约束过滤 → 六维度加权评分 → Top3（均衡 / 稳定易飞 / 性能·长航时·低成本）
- **交互**：参数锁定后重新推荐、方案冻结为只读快照（DSH 校验码）、可选命名（可跳过）
- **导出**：一键导出 18 个工作表的完整 .xlsx

## 本地预览

直接双击 `index.html` 即可（无需服务器）。

若想用本地服务器（某些浏览器对 `file://` 有更严格限制时）：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后浏览器打开 http://localhost:8000

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "RC aircraft conceptual design engine"
git branch -M main
git remote add origin https://github.com/<你的用户名>/dsh-rc-designer.git
git push -u origin main
```

推送后在仓库 **Settings → Pages** 中把 Source 设为 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
约 1 分钟后访问：

```
https://<你的用户名>.github.io/dsh-rc-designer/
```

## 已知边界

- 螺旋桨 / 电机模型为按模型界实测标定的统计模型，**绝对推力不确定度约 ±20%**；定型前请用厂家实测拉力表复核。
- 结构尺寸为等强度悬臂梁 + 薄壁圆管的工程估算，量产前请做静力试验。
- 翼型数据为模型尺度（Re ≈ 1e5~3e5）经验值，非风洞原始数据。
- 直升机模型只覆盖悬停功率与桨盘载荷，不含旋翼动力学、挥舞、尾桨配平与传动设计。
- 本工具不替代适航审定与安全评估。
